# savesync-manifests

База знаний SaveSync о расположении сохранений игр — store-агностичная,
открытая для комьюнити. Один файл = одна игра.

Формат файлов, правила slug'ов, структура репозитория и правила валидации
описаны в [SCHEMA.md](SCHEMA.md) — это нормативный документ, обязательный
к прочтению перед отправкой PR.

## Структура

```
manifests/<шард>/<slug>.yaml   # шард = первая буква slug'а или 0-9
blocklist.yaml                 # глобальный варн/блок-лист
tools/validate.py              # валидатор (запускается в CI на каждый PR)
```

## Как добавить игру

1. Прочитайте [SCHEMA.md](SCHEMA.md), особенно §3 (slug'и) и §4 (формат).
2. Создайте `manifests/<первая буква>/<slug>.yaml`.
3. Проверьте локально: `python tools/validate.py` (нужен `pyyaml`).
4. Отправьте PR — одна игра = один PR.

Переименование опубликованного slug'а запрещено: вместо этого старый файл
заменяется заглушкой `redirect: <new-slug>`.
